# Features to Improve Admin App UX and Functionality

## UX & Visual Enhancements
- [ ] **Haptic Feedback**: Add subtle haptic feedback for button clicks and successful actions on mobile (Capacitor Haptics).
- [ ] **Skeleton Loaders**: Implement skeleton screens for all list views and detail pages to improve perceived performance.
- [ ] **Pull-to-Refresh**: Add native-feeling pull-to-refresh on mobile list views (Orders, Leads, Products).
- [ ] **Swipe Actions**: Implement swipe-to-delete or swipe-to-archive on list items (similar to iOS Mail).
- [ ] **Floating Action Button (FAB)**: Add a contextual FAB for primary actions (e.g., "Add Project" in Portfolio) on mobile.

## Productivity & Efficiency
- [ ] **Batch Actions**: Enable multi-select in tables to perform bulk status updates or deletions.
- [ ] **Customizable Dashboard**: Allow admins to pin/reorder metrics cards on the dashboard.
- [ ] **Smart Search Filters**: Add "Saved Filters" for common views (e.g., "Orders due today", "Low inventory").
- [ ] **Inline Editing**: Allow quick edits of product prices or order statuses directly from the list view without full page transitions.
- [ ] **Keyboard Shortcuts Overlay**: A visible legend for the Command Palette and other shortcuts.

## Business Insights & Analytics
- [ ] **Lead Conversion Funnel**: A visual breakdown of how many leads turn into customers.
- [ ] **Product Performance Heatmap**: Map which products/packages are most popular by season or event type.
- [ ] **Export to CSV/PDF**: Quick export functionality for reports and invoices.
- [ ] **Inventory Alerts**: Push notifications when inventory levels for popular items are low.

## Mobile-Specific Features
- [ ] **Offline Mode**: Cache essential data (today's orders) so the app remains functional in areas with poor connectivity.
- [ ] **Direct Image Upload (Camera)**: Improved camera integration for uploading portfolio photos or scanning receipts.
- [ ] **Location-Based Check-ins**: For delivery/setup teams to mark arrival at event locations.

## Communication & Collaboration
- [ ] **Internal Staff Comments**: A private comment thread on orders for staff to communicate without the customer seeing.
- [ ] **Task Assignments**: Assign specific orders or tasks to team members with due dates.
- [ ] **In-App Messaging**: Real-time chat with other staff members.
